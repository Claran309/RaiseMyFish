# 12 · 安全、隐私与合规

> 这个系统接触账号、私信、花钱动作——安全不是加分项，是底线。

## 1. 凭据管理

| 凭据 | 存放 | 要求 |
|---|---|---|
| B站 cookie | 环境变量（`FISH_BILI_COOKIE`）或本地 `accounts` 表 | 不入仓、不落日志、不回显 |
| LLM API key | 环境变量 | 同上 |
| QQ 协议端 token | 环境变量/配置文件 | 同上 |
| 数据库密码 | 环境变量 | 同上 |

**硬规则**：
- 任何日志/错误信息不得包含凭据
- 前端/接口不返回完整凭据（最多显示后 4 位）
- 备份/导出时脱敏

### 1.1 账号管理（迁移 0008 `accounts`）

- **存储**：cookie/csrf 以**本地明文**存于 `accounts` 表，数据库文件权限即边界；
  项目为单机个人部署，明确接受该取舍。`accounts` 表不进入任何导出/备份脚本的敏感豁免。
- **解析链**：DB 活跃账号优先 → 环境变量 `FISH_BILI_COOKIE`/`_FILE` 兜底。
  Go 侧 bili 客户端每次请求经 `bili.Options.Resolver` 取当前凭据，Web 切换账号下一次请求生效；
  Node 采集/送礼、评论采集/发送与截帧等静态消费方在 fishd 启动时回填，**切换后需重启 fishd 才能生效**。
- **面板**：`/accounts` 只监听回环地址（沿用 127.0.0.1/::1 限制）。
  - 列表/添加/测试连接只返回 `cookie_masked`（仅保留 SESSDATA/bili_jct/buvid3 字段名，值替换为 `***`），
    响应与日志均不出现完整 cookie/csrf；
  - 添加账号、切换活跃、删除账号、测试连接都必须带 `confirm=yes`；
  - 删除当前活跃账号被拒绝（409），需先切换；
  - 请求体上限 16 KB，错误响应只给简短文案。
- **失效标记**：`nav` 返回未登录（`-101/-111`、401/403、`isLogin=false`）时标记 `status=invalid`；
  其他网络/解析错误只更新 `last_check`，不误判失效。失效不影响进程启动与既有环境变量兜底。
- **不落日志**：账号装配日志只记来源（db/env）、`account_id`、`mid`，凭据永不入日志。
- **限制**：`config.Load` 的严格校验仍要求启用直播/评论时配置环境变量 cookie；
  本阶段 DB 账号是「运行时覆盖」，尚不支持「零环境变量、纯 DB 启动」。

## 2. 隐私隔离

| 层 | 规则 |
|---|---|
| 数据层 | `events.private`、`memory_records.private` 字段 |
| 查询层 | 公开通道查询强制 `NOT private`（SQL 层） |
| 发送层 | 公开通道的 Sender 不接收 private 内容 |
| 日志层 | 私信内容不写日志正文（只记 id 与长度） |

**不依赖 prompt 自觉**——模型可能被诱导泄露。

## 3. 内容安全

- 人设规则里写清红线（辱骂、政治、色情、诱导）
- 回复前可选小模型检查（成本允许时）
- 敏感词/正则过滤作为兜底
- 被举报/封禁时的降级策略

## 4. 平台合规

| 平台 | 风险 | 应对 |
|---|---|---|
| B站 | 自动化风控、频率限制、评论仅自己可见（state 17） | 令牌桶、核验、失败退避、小号测试 |
| QQ 个人号 | 协议端封号/掉线 | 小号、协议端可替换、降级 |
| 虚拟主播开播 | 分区规则、内容审核 | 开播前读平台规则（P8） |
| 游戏 mod | 无（单机），但分发需遵守 mod 许可 | 遵守 SMAPI/作者许可 |

## 5. 行为边界

- 不冒充他人（人设是虚构角色，不冒充真人）
- 不诱导交易/转账
- 不主动索要隐私（密码、住址、身份证）
- 花钱动作（送礼）必须有额度、dry-run、账本
- 不自动加好友/拉群（除非用户明确要求）

## 6. 数据保留与删除

- 事件保留 90 天（之后归档）
- 记忆记录长期保留，支持 `fishctl memory delete <id>`
- 用户要求删除时：删记忆 + 事件 + 关联

## 7. 日志安全

- 日志目录仅本机可读
- 不记录私信全文
- 错误堆栈不包含路径以外敏感信息

## 8. 测试要求

- 凭据泄露扫描（grep 日志/代码）
- 隐私查询测试（公开通道查不到私密）
- 花钱工具 dry-run 测试
- 鉴权失败测试

## 9. 防坑清单

- ❌ cookie 写进配置文件并提交
- ❌ 日志打完整 prompt
- ❌ 公开通道能读出私信记忆
- ❌ 送礼无上限/无确认
- ❌ 用主号跑自动化
