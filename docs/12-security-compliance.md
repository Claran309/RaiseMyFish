# 12 · 安全、隐私与合规

> 这个系统接触账号、私信、花钱动作——安全不是加分项，是底线。

## 1. 凭据管理

| 凭据 | 存放 | 要求 |
|---|---|---|
| B站 cookie | 环境变量或本地加密文件（如 `FISH_BILI_COOKIE`） | 不入仓、不落日志、不回显 |
| LLM API key | 环境变量 | 同上 |
| QQ 协议端 token | 环境变量/配置文件 | 同上 |
| 数据库密码 | 环境变量 | 同上 |

**硬规则**：
- 任何日志/错误信息不得包含凭据
- 前端/接口不返回完整凭据（最多显示后 4 位）
- 备份/导出时脱敏

## 2. 隐私隔离

| 层 | 规则 |
|---|---|
| 数据层 | `events.private`、`memory_records.private` 字段 |
| 查询层 | 公开通道查询强制 `NOT private`（SQL 层） |
| 发送层 | 公开通道的 Sender 不接收 private 内容 |
| 日志层 | 私信内容不写日志正文（只记 id 与长度） |

**不依赖 prompt 自觉**——模型可能被诱导泄露。

## 3. 内容安全

- 人设规则里写清红线（辱骂、政治、色情、诱导）
- 回复前可选小模型检查（成本允许时）
- 敏感词/正则过滤作为兜底
- 被举报/封禁时的降级策略

## 4. 平台合规

| 平台 | 风险 | 应对 |
|---|---|---|
| B站 | 自动化风控、频率限制、评论仅自己可见（state 17） | 令牌桶、核验、失败退避、小号测试 |
| QQ 个人号 | 协议端封号/掉线 | 小号、协议端可替换、降级 |
| 虚拟主播开播 | 分区规则、内容审核 | 开播前读平台规则（P8） |
| 游戏 mod | 无（单机），但分发需遵守 mod 许可 | 遵守 SMAPI/作者许可 |

## 5. 行为边界

- 不冒充他人（人设是虚构角色，不冒充真人）
- 不诱导交易/转账
- 不主动索要隐私（密码、住址、身份证）
- 花钱动作（送礼）必须有额度、dry-run、账本
- 不自动加好友/拉群（除非用户明确要求）

## 6. 数据保留与删除

- 事件保留 90 天（之后归档）
- 记忆记录长期保留，支持 `fishctl memory delete <id>`
- 用户要求删除时：删记忆 + 事件 + 关联

## 7. 日志安全

- 日志目录仅本机可读
- 不记录私信全文
- 错误堆栈不包含路径以外敏感信息

## 8. 测试要求

- 凭据泄露扫描（grep 日志/代码）
- 隐私查询测试（公开通道查不到私密）
- 花钱工具 dry-run 测试
- 鉴权失败测试

## 9. 防坑清单

- ❌ cookie 写进配置文件并提交
- ❌ 日志打完整 prompt
- ❌ 公开通道能读出私信记忆
- ❌ 送礼无上限/无确认
- ❌ 用主号跑自动化
