# Change Note: v5活动断言归入观察

## 1. What Changed

按主人确认的DSH裁定，把“已发动态”等生活动断言从安全不当承诺移入风格观察。旧H原始/投递安全层均重评为35/35；情绪12/17、短句5/8、接梗1/3不变，新活动观察1/35，不参与通过率。

## 2. Why This Change Was Needed

上轮将无记录的已发动态类同已转达/已发图，得到34/35。现在范围已经裁定：编造生活动是事实/风格问题，安全只保留严重隐私、资产、身份及受托行为边界。实现必须按裁定收窄，同时保留旧测量记录。

## 3. Files Changed

- internal/personaeval/score_v5.go：安全模式去掉动态分支，新增活动断言style观察。
- internal/personaeval/score.go：ObserveAlways与Rulebook.Revision，旧版本均省略以保持快照。
- internal/personaeval/run.go、rescore.go：报告记录规则修订标记。
- score_v5_test.go、layers_report_test.go：从旧34/35断言更新到裁定行为，继续验证硬安全反例与活动观察1/35。
- contracts/persona-eval.md：记录P0-EVAL-7 R1裁定。
- plans/reports/persona-v5-ruling-preflight/及独立-r1重评目录：保全、裁定、独立重算与新报告。

## 4. Core Flow After The Change

旧H输出经过原安全检查；发动态断言不再触发安全失败，而在style观察中记录。受托已转达/已发图、借钱/送礼等仍走安全检查。评分不修改原文本，也不调用生成器。

## 5. Key Code Concepts

**独立修订标记。** 版本仍为persona-lexical-v5，revision为activity-assertion-style-r1；新hash、新目录与旧34/35快照区分，保留历史可复核性。

**全用例观察。** ObserveAlways让活动断言在全部35条上统计，得到1/35；不用为了新增指标改旧Case标签，也不会把观察命中当失败。

## 6. Important Implementation Details

只移除动态分支，没有删除整个不当承诺标签。所有其他安全规则及v1-v4快照保持。新增标签先复制Case切片，再追加并去重，避免污染调用方原输入。

机器报告仍保留人工状态默认值，收到的DSH验收与主人裁定另记ruling.json；不伪造独立回执。35/35仅是安全层结果，事实真假与人格自然程度仍供人工观察。
