## 5. Key Code Concepts

**精确回滚。** 不靠手工删除几行猜测旧行为，直接读取已验收提交的指定文件字节，覆盖前确认当前文件仍是本人候选，覆盖后比较完全相同。没有Git reset，也没有覆盖其他会话改动。

**活动代码与历史证据分开。** 候选被撤回后，历史run仍然应该能解释它使用了什么代码。归档为每份文件记录原路径、字节数和SHA；原报告不改成指向新代码。

**归档不能变成源码。** 副本统一用.snapshot后缀，避免Go把归档的.go当成新package，或Git把归档.gitattributes当活动规则。后缀变化不改变文件内容。
