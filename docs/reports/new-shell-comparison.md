# 换新壳横评：从 DSH 到 fishd

> 日期：2026-11-11
> 口径：本机实测 + 推算（标注 ★ 的是估算/推算，非直接计量）

---

## 一、一句话结论

**旧壳（DSH）**：贵、慢、靠会话——**像租跑车按小时计费**
**新壳（fishd）**：便宜、快、常驻——**像自己养了台车**

---

## 二、成本横评

| 项 | 旧壳（DSH） | 新壳（fishd） |
|---|---|---|
| **计费模式** | 按会话/时长（20 元/5 小时 ≈ **4 元/小时**） | 按 token 实销（deepseek-chat：输入 ¥2.0/百万、输出 ¥8.0/百万） |
| **5 小时** | **¥20** | **¥5** |
| **节省** | — | **¥15（75%）** |
| **闲置成本** | 会话开着就烧 | **0**（不回复不花钱） |
| **计费透明度** | 黑盒（不知道哪条花多少） | **逐条可查**（llm_usage：in/out/cost/ms） |

**省钱点**：
```
旧壳：挂着就烧（4 元/小时 × 24h = 96 元/天）
新壳：不回复不烧（只按实际 token 计）→ 深夜挂机成本归零
```

**数据来源**：`llm_usage` 真实 cost_usd（427 次已计价 $0.4202 ≈ ¥3）+ 推算 5h ≈ ¥5（主人口径）。

## 三、回复速度横评

| 项 | 旧壳（DSH） | 新壳（fishd） |
|---|---|---|
| **单条回复延迟** | **20-40 秒**（ReAct 完整推理链） | **0.78-2.81 秒**（实测 5 个样本） |
| **提速** | — | **约 10-20 倍** |
| **并发能力** | 单会话串行 | **8 并发**（LLM + 调度） |
| **高峰表现** | 排队越来越慢 | **8 并发消化**（排队 ~2-3 秒） |
| **超时保护** | 无（等 30 秒） | **8 秒预算 + 60 秒丢弃**（不拖） |

**为什么快**：
```
旧壳：完整 ReAct 推理链（20-40 秒）——想得深但慢
新壳：ReAct 3 步 + 8 秒预算 + 降级兜底——快而不失准
```

## 四、记忆与人格横评

| 项 | 旧壳（DSH） | 新壳（fishd） |
|---|---|---|
| **记忆** | diary 日记（软记忆，低置信） | **memory_records 结构化**（fact/preference/promise）+ 向量召回 |
| **跨会话** | 靠人工 recall | **自动**（全局库 + 侧写 + 最近 7 天） |
| **观众档案** | people/*.md（统计） | **viewer_profiles + 侧写**（LLM 五字段 + 统计降级） |
| **注入方式** | 工具查（可能不查） | **主动注入**（观众档案+记忆+乙档案+名单，零工具） |
| **金主/关系** | 无 | **13 金主名单**（feeders）已进记忆 |
| **人格** | soul 单文件 | **soul + context + rules + samples**（分层） |

## 六点五、实测案例（真实弹幕）

> 以下均为直播间真实对话（events 表可查），不是编的。

