```

✅ 正确：curl -X POST "http://127.0.0.1:8090/api/shutdown?confirm=yes" -H "X-Panel-Token: <token>"
```

### 检查是否断流

```bash

psql -c "SELECT to_char(at,'HH24:MI:SS'),dir,status FROM events WHERE session='1992099976' AND at > now()-interval '3 minutes' ORDER BY at DESC LIMIT 5"
# 采集正常应该每分钟都有 in/out；如果 0 条而娇娇在播 → 查是否有两个 node.exe
```

## 4. 关键坑（下一个会话别再踩）

1. **强杀 fishd = 孤儿 node = 弹幕断流**（见第 2 节）
2. **fishd.exe（编译版）写日志 Access denied**：连用户目录都被拒，疑似 Defender/AppLocker 限制 exe 写文件；**用 go run 版**（`start-fishd.bat`）绕开
3. **面板费用必须按官方峰谷价**：峰段 UTC 周一~周五 01-04/06-10，谷段半价；缓存命中 $0.003-0.006（不是 0.07！）
4. **公共 SearXNG 不可用**：searx.be 等返回 Anubis 验证页（HTTP 200 但内容假）；要联网搜索得用 API key（Serper 2500 次免费，能连）
5. **`.env` 路径被安全策略拦**：本鱼不能直接读/写 `.env`、不能跑 `--env-file .env`；用户自己填，或用脚本包装
6. **记忆会被公式化**：鱼的「认一个缸」3 天 130 次，观众直接吐槽；已加口头禅记忆，但根治靠 soul 的反公式化
7. **改名/别名要进记忆**：`viewer_aliases.yaml` 只是代码解析用，**模型上下文里没有**——别名必须写成记忆（或让重复度提炼自动生成）
8. **vision 会猜游戏**：默认 prompt 没限制时，像素风画面会被认成「星露谷」；已加「不确定就说名字看不清」
