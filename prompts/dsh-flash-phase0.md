# 给 DSH + flash 的提示词（零散辅助）

> 只做小任务，不承担模块开发。模块开发交给 Codex / WorkBuddy。
> 角色：零散辅助（测试补齐、文档同步、小修、脚本）。

---

## 通用要求

- 先读 `plans/assignment.md` → `AGENTS.md`
- 只碰：`scripts/`、测试文件、你被明确指派的单文件
- 不碰：`contracts/`、`go.mod`、`plans/`、别人的模块目录
- 争议升级给 Codex；文档与验收由本鱼负责
- 完成后 `go test ./...`，commit，汇报

---

## 可用任务清单（按需发一条）

```
任务：补测试

范围：<指定模块> 的单元测试
要求：覆盖 AGENTS.md 约定的关键路径；不修改实现逻辑；go test ./... 全绿
验收：新增用例数、覆盖点、失败原因汇总
```

```
任务：同步文档

范围：<指定文档>
要求：按最新实现更新；不改其他文件；提交前跑链接校验
验收：改动摘要 + 链接有效
```

```
任务：小修

范围：<编译错误 / lint 问题 / 格式>
要求：只修问题本身，不重构；go vet / gofmt 通过
验收：修复列表
```

```
任务：维护 dev.ps1

范围：scripts/dev.ps1
要求：启动/停止/状态三路径可用；不引入依赖
验收：语法校验 + 手动跑一遍
```
