## 执行规则

1. 每个 Phase 有「退出标准」，不达标不进下一个
2. 任务按编号顺序做；有依赖的标注
3. 每完成一个任务：更新本表 + 写一句结果
4. 不跨 Phase 提前实现（接口留缝即可）
5. 设计缺口记录在该 Phase 的「待定」区，不自行发明方向

## 阶段间的「可用」原则（ADR-0014）

每个通道闭环完成后即可上线使用，不等全项目：
- Phase 0 完成 → 直播弹幕可以真实运行
- Phase 1 完成 → 评论、私信可用
- 通道通过配置独立开关
