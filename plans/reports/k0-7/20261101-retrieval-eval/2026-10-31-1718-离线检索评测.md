# Change Note: 独立离线检索评测

## 1. What Changed

新增独立离线质量评测包与knowledgeeval命令。输入是已冻结的100条查询和公开知识目录，输出是输入hash、逐条相关ID/返回ID、范围、版本、预算摘要与质量门禁。原500条知识、Reader、Brain、人格、配置和fishd均未修改；只有新评测程序调用它们现有的接口。

## 2. Why This Change Was Needed

“读到三条知识”无法证明“读到相关且有权读取的知识”。评测把相关率、正例覆盖、负例误召回、范围隔离分开检查，避免用全public库的空返回假装证明私密隔离。冻结发生在首次真实Reader之前，防止看到结果后重新挑题。

## 3. Files Changed

- internal/knowledgeeval/eval.go：查询用例及结果类型、严格100条校验、Reader依赖注入、按实际返回条目计算相关率。
- internal/knowledgeeval/budget.go：真实Brain与内存固定Provider/Usage；候选知识和空知识各组装一次，对比序列化后的字节差与预算审计。
- internal/knowledgeeval/runner.go：先写freeze.json，再从同一份内存原字节复制临时快照；公开库、合成权限库、合成排序库分别构造Reader。
- internal/knowledgeeval/eval_test.go：分母/N/A、范围与Top3、取消与错误、预算、严格用例、输出目录拒绝覆盖。
- internal/knowledgeeval/testdata/cases.jsonl：独立于原人格35条的60正例/20负例/20权限反例。
- internal/knowledgeeval/testdata/batch-synthetic-acl.md：非真实私密和仅QQ私聊scene的公开合成资料。
- internal/knowledgeeval/testdata/batch-synthetic-order.md：独立碰撞条目，用固定人工预期验证标题/关键词/priority/ID顺序。

- cmd/knowledgeeval/main.go：命令行入口，未指定新output或加载失败返回1，质量门禁失败返回2。
- plans/reports/k0-7/20261101-retrieval-eval/：本次独占开发证据。根据任务路径边界，教学说明放在此目录，不向docs/update写入。

## 4. Core Flow After The Change

```text
读取100条冻结查询与公开库原字节
  -> 校验60/20/20与合法范围
  -> 写入case/fixture/代码/公开库文件hash及Revision
  -> 临时目录逐字节复制全部公开库
  -> 另一个副本增加合成私密batch
  -> 原FileReader召回并Context.Validate
  -> 根据冻结ExpectedIDs评分
  -> 真实Brain + 内存fake比较候选与空知识预算
  -> 同输入合法源scope镜像、独立Top3顺序结构检查
  -> 核对输入未变，写新results/report
```

## 5. Key Code Concepts

相关率以实际返回条目为分母：46个相关返回/56个全部返回，而不是“有返回的正例数/正例数”。覆盖率则回答60个确有接法的场景有多少召回至少一项预期；本次43/60。两者不能互相替代。

镜像控制只改变可信Scope，不改变query。反例的私密资料如果在合法范围也召回不到，那么反例空返回只能证明没有命中；所以必须同时验证合法范围命中。20个镜像不进入100条质量指标的分母，不能靠合成简单题抬高质量。

Revision按白名单相对路径与原文件字节hash构造，生产库与合成库不同。测试先冻结这些版本，再从同一内存字节创建Reader；不会评测到半途变动的目录。

fake Provider替代外部调用而保留真实Brain。它不返回虚构token数量，Usage也只在内存记未知用量。知识预算采用UTF-8消息字节加64框架余量，不能称为精确模型token或真实费用。

## 6. Important Implementation Details

Reader/Brain只收到正文与范围，评分预期不传给它们。每次返回Context都校验合法性并限三条；重复ID属于非法Context，不能重复计相关数。错误和取消不转换为空命中。

输出目录通过os.Mkdir独占创建，已存在就报错。freeze先落盘，之后才首次调用真实Reader。临时目录由程序清理；证据只保存ID、scope、标签、hash、版本与预算，不保存真实prompt或知识正文。

20精确标题与20含标题自然句均20/20命中，但20无标题语义场景仅3/20。17条遗漏均没有目标title/keywords/有效tag词面，符合当前词面能力边界；详细静态复核在coverage-review.md。当前结果不构成修改库或Reader的授权。
