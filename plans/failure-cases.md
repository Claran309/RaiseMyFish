# 典型失败案例（给 Qoder 的样例）

> 来源：2026-11-05 测试（主人直播间 30308220），events 归档实证。
> 用途：修复 H4/H5/H8/H7 的对照样例。

## 案例 1：意图误判（H8）——「XX 是谁」被当成「你是谁」

```
IN  21:32:13  X奇迹与你X：「X奇迹与你X 是谁」
OUT 21:32:14  「@X奇迹与你X 本鱼啊，大肥鱼，看直播的那条」
期望：「X奇迹与你X 是个老熟人，说过 161 句，话不少」
```

## 案例 2：记忆召回失败（H4）——数据在但说不知道

```
IN  21:54:32  X奇迹与你X：「弓长三益是谁」
OUT 21:54:43  「@X奇迹与你X 不认识，本鱼没听过这号人」
数据：弓长三益 events 12 条 + viewer_profiles 1 条
期望：「弓长三益？哦他啊，说过 12 句，老熟人」
```

## 案例 3：谐音误判（H5）——谐音当歌词

```
IN  21:55:28  Claran309：「弓长三溢是谁」（益→溢 同音）
OUT 21:55:32  「@Claran309 弓长三溢？听着像人名歌词填空那套」
期望：「弓长三溢？你是说弓长三益吧，他常来」
```

## 案例 4：接不上前文（H7）——重复误判

```
IN  21:56:15  X奇迹与你X：「X奇迹与你X 是谁」
OUT 21:56:17  「@X奇迹与你X 本鱼啊，大肥鱼一条」
期望：同案例 1（认人）
```

## 案例 5：记忆聚焦偏科（ReAct 上下文）

```
IN  21:31:34  X奇迹与你X：「绷真就记得娇娇和老大」
观察：鱼对「娇娇/主人」记得清楚，对其他观众（迁移的 194 人档案）不记得
```

## 修复对照

| 案例 | 根因 | 修复 |
|---|---|---|
| 1/4 | 意图识别：问「XX 是谁」→ 当成问自己 | H8：rules 加「XX 是谁 = 问那个用户」 |
| 2 | 记忆召回：viewer 档案没喂进上下文/ReAct 没查 | H4：查 memory_search 路径 + 档案注入 |
| 3 | 谐音：昵称精确匹配失败 | H5：昵称模糊匹配（编辑距离/拼音） |
| 5 | ReAct 上下文缺「观众名单/最近对话」 | H7：完整上下文注入 |
