# P0.5 / P6 思考链计划（agent 思考式回复）

> 背景：P0 当前是**单步 LLM**（事件→可选召回→一次调用→回复），智商低于旧 DSH「吊新会话多步思考+call tool」方案（DSH 30~40 秒/条 vs P0 1 秒/条）。
> 本计划是「既快又聪明」的折中路线，P0 完成后再启动。

## 现状差距

| 能力 | 旧 DSH | P0 当前 |
|---|---|---|
| 回复速度 | 30~40 秒 | **1 秒内** |
| 思考 | 多步 agent 会话 | 单步 |
| 工具调用 | ✅（call tool） | ❌ |
| 记忆/知识 | agent 可主动查 | 预组装（固定召回） |

## B 档：两段式轻量思考（P0.5，成本小）

```
弹幕事件
  → 第一段：轻量判断（小 prompt/便宜模型）
      "这条需要查记忆/梗/状态吗？查什么？"
  → 按判断组装上下文（记忆/知识/状态）
  → 第二段：主模型生成回复
```

- 判断失败/超时 → 降级直接生成（不阻塞，延迟预算 +300ms 内）
- 判断输出结构化（JSON：{need_memory: bool, need_knowledge: bool, need_status: bool}）
- 只是「多一次便宜调用」，不是 ReAct 循环
- 验收：延迟 P95 ≤ 2s；对「你上次说的那个」类追问的召回命中率提升

## C 档：完整 ReAct（P6，随工具层）

```
弹幕事件 → 主模型（带工具定义）
  → 思考 → 调工具（查记忆/查知识/查状态/查直播间历史）
  → 观察 → 再思考 → ...（最多 N 步）→ 回复
```

- 依赖 MCP/工具层（P6）
- 延迟预算大（多轮工具调用）
- 只在「需要多步」的弹幕上触发（简单弹幕仍走单步）

## 触发策略（B 档）

1. 默认全部走单步（快）
2. 命中「追问/指代/情绪强」关键词 → 走两段式
3. 两段式判断为「不需要额外信息」→ 直接生成（不多调）

## 验收标准

- 延迟：单步 P95 ≤ 1.5s；两段式 P95 ≤ 2.5s
- 召回提升：对「刚才说的那个」「之前你提过」类追问，引用记忆命中率 ≥ 60%
- 降级：判断/召回失败不阻塞回复（fallback 单步）
- 不引入工具调用依赖（B 档）；C 档工具层另立计划

## 排期

- P0.5（P1 前）：两段式轻量思考
- P6：ReAct + 工具层
