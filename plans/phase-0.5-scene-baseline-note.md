# 知识库计划的场景基线撤回说明

本说明由Codex依据主人转交的DSH负面复核发布，只继续规划，不实现知识库、不调用模型。它修正 [知识实施计划](phase-0.5-implementation.md) 第5节仍保留的旧P0-A开发步骤；正式装配真源为 [P0-BRAIN-2-R1](../contracts/brain.md)。

## 当前结论

- P0-A已执行且DSH判为负优化：基线v2为20/35，实验为13/35。不能再把“scene移入instructions+长说明”作为知识库的必做前置，不照着原测试片段重新开发或重跑35条。
- 场景源码恢复008beb6，原static scene仍在context JSON；知识库未来若获准实现，其资料继续保持资料属性，不能借知识接缝重新引入已撤回的长指令。
- 知识库功能尚未因“可以继续计划”而获准实现/迁移/付费对照；现有独立契约裁决、私密查询隔离、预算规范等其他任务成果保留，不在本轮重审或覆盖。
- A0行为意图清单可继续独立人工审查，评分v2和旧run保持冻结。人格B/H、新模型或轻量指令候选仍需明确方案和授权，不以本次回滚自动放行。

## 知识计划维护者需同步的最小差异

1. 第5节P0-A改为“已执行并撤回；核对回滚零调用证据”，删除活动任务中的scene-outside-context强制测试及再次真实运行指令。历史实验可保留链接。
2. P0-B/H中的“用A的相同代码”改为“用后续批准的活动基线代码”，避免继承负面候选。
3. 任务看板和工时/调用预算不再把A算成待执行的新批次；A既有35次费用只属于原run，不重复预算后自动执行。
4. Brain后续Knowledge契约增补在本轮写入窗口释放后进行；以当前第9节R1为底，不恢复第8节历史要求。
