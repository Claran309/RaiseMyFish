## 任务 1：dev.ps1 修订（P0-G06）

文件：`scripts/dev.ps1`（或仓库根 dev.ps1，先确认实际路径）

要求：
1. **创建日志目录**：启动前自动创建 `logs/`（已存在则跳过）
2. **修复 go run 父子进程生命周期**：当前 `go run` 会派生临时子进程，`Stop-Process` 只杀主进程会留孤儿；改为 `go build` 出可执行文件再启动，或记录子进程 PID 树并杀整棵树
3. **优雅退出**：SIGINT/SIGTERM 时先停 fishd 再退出，超时强杀
4. **重复启动检查**：启动前检查是否已有 fishd 在跑（进程名或状态文件），有则提示并退出，不重复起
5. **补验证命令与未通过项记录**：脚本里带注释说明怎么验证

测试：能实际跑（dev.ps1 启动 → 检查日志目录/进程 → Ctrl+C 退出无孤儿）
